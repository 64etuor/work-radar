# G3-PR1 — Project Workspace View (read-only) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only "project" axis to the skills sidebar — group the already-scanned per-repo skills into per-project workspaces a user can select and filter by.

**Architecture:** A new infallible Rust core (`list_skill_workspaces_core`) aggregates skills per enabled Local repo by reusing the existing `repo_skill_roots` + `scan_external_skills_core` path (root/path logic stays in scan.rs — C6, no FE path inference). A thin command exposes it; the FE builds `workspace:${repoId}` nav items whose `match` is a backend-provided `memberPaths` Set lookup and renders them as a labeled group in the existing sidebar. Pure read-only: no writes, no migration, no network, no job spawn.

**Tech Stack:** Rust (Tauri 2 command, specta-typed binding), sqlx (read-only repo fetch), React + TanStack Query, vitest, cargo test.

**Spec:** `docs/superpowers/specs/2026-06-01-skills-manager-g3-pr1-project-workspace-view-design.md`

**Conventions for every commit in this plan:**

- Export cargo onto PATH first (husky pre-commit runs `cargo fmt` + frontend guards, else exit 127):
  `export PATH="$HOME/.cargo/bin:$PATH"`
- Rust commands live under `src-tauri/`; run cargo from `src-tauri/`.
- bindings.ts is **generated by `cargo test`** (do not hand-edit). Drift must be additive only.
- Do **not** push. Local commits only (user pushes explicitly).

```rust
/// enabled Local 레포별 프로젝트 워크스페이스 집계(G3-PR1, #16). 읽기 전용·infallible — 루트 해석과
/// 스캔은 기존 `repo_skill_roots`/`scan_external_skills_core`를 재사용해 경로 의미의 단일 출처(C6)를
/// 유지한다. `repo_skill_roots`가 이미 `Provider::Local && enabled && non-empty local_path` 필터라
/// 비대상 레포는 빈 roots → 스킵. **스킬 0개 레포는 결과에서 제외**(뷰 전용 PR에서 빈 프로젝트는
/// 노이즈). 개별 레포 스캔은 IO 오류를 삼키고 빈 결과를 반환하므로(scan_external_skills_core) 절대
/// 패닉하지 않는다 — 부재 경로 = 빈 워크스페이스로 graceful.
pub(crate) fn list_skill_workspaces_core(repos: &[Repo]) -> Vec<SkillWorkspace> {
    let mut out: Vec<SkillWorkspace> = Vec::new();
    for repo in repos {
        let roots = repo_skill_roots(std::slice::from_ref(repo));
        if roots.is_empty() {
            continue; // Github/비활성/빈 경로 레포
        }
        let skills = scan_external_skills_core(&roots);
        if skills.is_empty() {
            continue; // 스킬 0개 → 워크스페이스 미생성
        }
        let local_path = repo
            .local_path
            .as_deref()
            .map(str::trim)
            .unwrap_or("")
            .to_string();
        let label = Path::new(&local_path)
            .file_name()
            .and_then(|s| s.to_str())
            .filter(|s| !s.is_empty())
            .map(str::to_string)
            .unwrap_or_else(|| local_path.clone());
        let member_paths: Vec<String> = skills.iter().map(|s| s.path.clone()).collect();
        out.push(SkillWorkspace {
            repo_id: repo.id.clone(),
            label,
            root_path: local_path,
            skill_count: member_paths.len() as i32,
            member_paths,
        });
    }
    out
}
```

```ts
/**
 * 프로젝트 워크스페이스 사이드바 항목(G3-PR1, #16). 백엔드 `list_skill_workspaces`가 준 멤버십

 * provider 항목과 달리 별도 "프로젝트" 섹션에 렌더되며 드래그 재정렬 대상이 아니다(`pinned: true`).
 */
export function buildSkillWorkspaceNav(
  workspaces: SkillWorkspace[] | undefined,
): SkillEnvNavItem[] {
  return (workspaces ?? []).map((w) => {
    const members = new Set(w.memberPaths);
    return {
      id: `workspace:${w.repoId}` as SkillEnvNavId,
      label: w.label,
      match: (s: Skill) => s.sourcePath != null && members.has(s.sourcePath),
      pinned: true,
    };
  });
}
```
