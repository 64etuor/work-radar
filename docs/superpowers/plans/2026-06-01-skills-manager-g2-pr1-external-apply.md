# G2-PR1 — External-dir apply (symlink) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply a managed central-library skill to an external agent dir (`~/.{claude,codex,openclaw,hermes}/skills/<name>`) as a reversible, audited symlink, and remove it safely.

**Architecture:** New `src-tauri/src/skills/apply.rs` with a pure-fs core (hermetic tempdir tests) + 3 thin `#[tauri::command]` wrappers. Apply creates a symlink external→central; unapply removes only symlinks we own (canonical target under central root). Applied-state is _derived from disk_ (no new table, no migration) — matches the existing scan "disk SSOT, no cache" design (INVARIANT #7). Every write is `audit()`-logged (ADR-0006 rail ①). Pure file I/O — no job spawn (#1/#2 unaffected).

**Tech Stack:** Rust (sqlx/SQLite, tauri 2, specta/tauri-specta), React/TS frontend. Reuses `central_repo::{central_skill_dir, provider_segment, sanitize_segment, list_managed_dirs}`, `scan::{resolve_skill_roots, SkillRootEnv}`, `audit_log::audit`.

**Spec:** `docs/superpowers/specs/2026-06-01-skills-manager-g2-external-apply-design.md`

/// 디렉터리 심링크 생성(크로스플랫폼). 주 타깃은 darwin(unix).
#[cfg(unix)]
fn make_symlink(target: &Path, link: &Path) -> std::io::Result<()> {
    std::os::unix::fs::symlink(target, link)
}
#[cfg(windows)]
fn make_symlink(target: &Path, link: &Path) -> std::io::Result<()> {
    std::os::windows::fs::symlink_dir(target, link)
}

/// `link`이 **우리가 만든 심링크**인지(= 심링크이고 타깃이 `expected_central_dir`) 판정.
/// 끊긴 심링크도 raw read_link 비교로 인식하고, 양쪽이 실존하면 canonicalize로도 확인한다.
/// 실제 dir·외부(foreign) 심링크·부재는 모두 false → 호출자가 거부/스킵한다(데이터 손실 가드).
fn is_our_symlink(link: &Path, expected_central_dir: &Path) -> bool {
    let Ok(meta) = std::fs::symlink_metadata(link) else {
        return false; // 부재(끊긴 심링크는 Ok이므로 여기서 안 걸림).
    };
    if !meta.file_type().is_symlink() {
        return false; // 실제 dir/파일 → 우리 것 아님.
    }
    let Ok(target) = std::fs::read_link(link) else {
        return false;
    };
    if target == expected_central_dir {
        return true; // raw 타깃 일치(끊긴 심링크 포함).
    }
    match (
        std::fs::canonicalize(link),
        std::fs::canonicalize(expected_central_dir),
    ) {
        (Ok(a), Ok(b)) => a == b,
        _ => false,
    }
}

/// core: 앱 핸들 비의존(tempdir hermetic). central 스킬을 external dir에 심링크로 적용.
/// 반환 = 만들어진(또는 이미 우리 것인) 링크 경로. 외부 루트가 없으면 생성한다(스킬 dir 자체 — benign).
pub(crate) async fn apply_core(
    pool: &SqlitePool,
    central_root: &Path,
    external_root: &Path,
    provider: SkillProvider,
    name: &str,
) -> Result<PathBuf, AppError> {
    let provider_str = provider_segment(provider);
    let seg = sanitize_segment(name);
    let src = central_skill_dir(central_root, provider_str, &seg);
    if !src.join("SKILL.md").is_file() {
        return Err(AppError::not_found(
            "skills.apply.no_source",
            "중앙 라이브러리에 해당 스킬이 없습니다.".to_string(),
        ));
    }
    let link = external_root.join(&seg);
    // 이미 무언가 있으면: 우리 심링크면 멱등 성공, 아니면 충돌 거부(절대 덮어쓰지 않음).
    if std::fs::symlink_metadata(&link).is_ok() {
        if is_our_symlink(&link, &src) {
            return Ok(link); // 멱등 no-op.
        }
        return Err(AppError::terminal(
            "skills.apply.collision",
            "대상 경로에 다른 파일/스킬이 이미 있습니다(덮어쓰지 않음).".to_string(),
        ));
    }
    std::fs::create_dir_all(external_root)?; // 외부 skills/ 루트 보장(부재 시 생성).
    make_symlink(&src, &link).map_err(|e| {
        AppError::terminal("skills.apply.symlink", format!("심링크 생성 실패: {e}"))
    })?;
    audit(
        pool,
        "apply",
        "external_dir",
        &link.to_string_lossy(),
        Some(&src.to_string_lossy()),
        Some("symlink"),
    )
    .await?;
    Ok(link)
}
```

/// core: 우리 심링크만 제거(가역). 실제 dir/외부 심링크 = `not_ours` 거부, 부재 = no-op 성공.
pub(crate) async fn unapply_core(
    pool: &SqlitePool,
    central_root: &Path,
    external_root: &Path,
    provider: SkillProvider,
    name: &str,
) -> Result<(), AppError> {
    let provider_str = provider_segment(provider);
    let seg = sanitize_segment(name);
    let src = central_skill_dir(central_root, provider_str, &seg);
    let link = external_root.join(&seg);
    if std::fs::symlink_metadata(&link).is_err() {
        return Ok(()); // 부재 → 멱등 no-op(audit 안 함).
    }
    if !is_our_symlink(&link, &src) {
        return Err(AppError::terminal(
            "skills.apply.not_ours",
            "대상이 우리가 만든 심링크가 아닙니다(제거하지 않음).".to_string(),
        ));
    }
    std::fs::remove_file(&link).map_err(|e| {
        AppError::terminal("skills.apply.unlink", format!("심링크 제거 실패: {e}"))
    })?;
    audit(
        pool,
        "unapply",
        "external_dir",
        &link.to_string_lossy(),
        Some(&src.to_string_lossy()),
        Some("symlink"),
    )
    .await?;
    Ok(())
}

/// 디스크에서 적용 상태 유도: managed 스킬 각각이 자기 provider 외부 루트에 우리 심링크로 있는지.
/// `roots` = provider별 (대표) 외부 스킬 루트 1개. 없으면 그 provider는 스킵. 새 표/캐시 없음.
pub(crate) fn list_applied_core(
    central_root: &Path,
    roots: &[(SkillProvider, PathBuf)],
) -> Vec<AppliedSkill> {
    let mut out = Vec::new();
    for (provider, central_dir) in list_managed_dirs(central_root) {
        let name = central_dir
            .file_name()
            .map(|n| n.to_string_lossy().into_owned())
            .unwrap_or_default();
        let Some((_, ext_root)) = roots
            .iter()
            .find(|(p, _)| provider_segment(*p) == provider_segment(provider))
        else {

            out.push(AppliedSkill {
                provider,
                name,

/// 프로세스 env로 해석한 provider별 (대표) 외부 스킬 루트. provider 첫 출현만 유지
/// (Codex의 `.codex`가 `.agents`보다 먼저 → 대표는 `.codex/skills`). 적용/목록 글루.
pub(crate) fn apply_roots() -> Vec<(SkillProvider, PathBuf)> {
    let mut seen: Vec<&'static str> = Vec::new();
    let mut out: Vec<(SkillProvider, PathBuf)> = Vec::new();
    for r in resolve_skill_roots(&SkillRootEnv::from_process()) {
        let seg = crate::skills::central_repo::provider_segment(r.provider);
        if seen.contains(&seg) {
            continue;
        }
        seen.push(seg);
        out.push((r.provider, r.path));
    }
    out
}

/// 단일 provider의 대표 외부 루트(없으면 None — 적용 미지원 provider).
pub(crate) fn primary_external_root(provider: SkillProvider) -> Option<PathBuf> {
    let want = crate::skills::central_repo::provider_segment(provider);
    apply_roots()
        .into_iter()
        .find(|(p, _)| crate::skills::central_repo::provider_segment(*p) == want)
        .map(|(_, path)| path)
}
```
