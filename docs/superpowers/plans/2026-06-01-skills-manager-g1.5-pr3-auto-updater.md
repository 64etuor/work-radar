# G1.5-PR3 — Skill Auto-Updater Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Keep all commits LOCAL — do NOT push. Push only when the user explicitly asks.**

**Goal:** Opt-in, bounded, fetch-only upstream update checks for network-installed managed skills: per-skill auto-update toggle, a manual "check for updates" (re-resolve upstream commit → stage if newer), a reversible "apply" (backup → replace central from staging → bump commit), an "update available" badge, and an opt-in **one-pass** on-launch check. **Never runs/executes a skill; never spawns a codex job** (#1/#2).

**Architecture:** New `src-tauri/src/skills/updater.rs`. The provenance table `skill_source` (migration 0040, already shipped in PR1) already has `auto_update`, `staged_commit`, `last_checked_at` — **no new migration**. Check = reuse PR1's `remote::{parse_source, fetch_tarball_bytes, extract_tarball}` to re-resolve the upstream commit; if newer than `installed_commit`, copy the new content into a staging area (`app_data_dir/skills-staging/<provider>/<name>/`) and record `staged_commit`. Apply = take a full pre-apply library snapshot (reuse PR2's `backup::backup_library_core`), replace the central copy from staging (reuse `central_repo::import_to_central`), promote `staged_commit → installed_commit`, audit. The on-launch trigger reads an `app_config` flag and runs exactly one bounded pass. All network is in Rust, token from keychain (public-repo-first = `None` this round), bounded retry already inside `fetch_tarball_bytes`.

**Tech Stack:** Rust (sqlx SQLite, reqwest via existing `fetch_tarball_bytes`, `chrono::Utc`), tauri-specta bindings, React + @tanstack/react-query, shadcn/ui.

**Scope note / split option:** Tasks 1–4 + 6 (the *manual* updater: toggle, check, stage, apply, FE) form a shippable unit on their own. Task 5 (the *on-launch* opt-in trigger: `app_config` flag + boot spawn) is the only part touching app-boot glue and can be split into a follow-up **PR3b** if PR3 grows too large or boot wiring proves entangled. Decide at Task 5.

/// per-skill auto-update opt-in 토글.
pub(crate) async fn set_auto_update(
    pool: &SqlitePool,
    provider: &str,
    name: &str,
    enabled: bool,
) -> Result<(), AppError> {
    sqlx::query(
        "UPDATE skill_source SET auto_update = ?, updated_at = datetime('now') \
         WHERE provider = ? AND name = ?",
    )
    .bind(enabled as i32)
    .bind(provider)
    .bind(name)
    .execute(pool)
    .await?;
    Ok(())
}

/// 업데이트 확인 결과 기록: staged_commit(None=최신/비움, Some=새 버전 staging) + last_checked_at.
pub(crate) async fn record_update_check(
    pool: &SqlitePool,
    provider: &str,
    name: &str,
    staged: Option<&str>,
    checked_at: &str,
) -> Result<(), AppError> {
    sqlx::query(
        "UPDATE skill_source SET staged_commit = ?, last_checked_at = ?, updated_at = datetime('now') \
         WHERE provider = ? AND name = ?",
    )
    .bind(staged)
    .bind(checked_at)
    .bind(provider)
    .bind(name)
    .execute(pool)
    .await?;
    Ok(())
}

/// apply: installed_commit를 새 값으로 승격 + staged_commit 비움.
pub(crate) async fn promote_staged_commit(
    pool: &SqlitePool,
    provider: &str,
    name: &str,
    new_installed: &str,
) -> Result<(), AppError> {
    sqlx::query(
        "UPDATE skill_source SET installed_commit = ?, staged_commit = NULL, updated_at = datetime('now') \
         WHERE provider = ? AND name = ?",
    )
    .bind(new_installed)
    .bind(provider)
    .bind(name)
    .execute(pool)
    .await?;
    Ok(())
}

/// auto_update=1인 (provider, name) 키(on-launch 대상).
pub(crate) async fn auto_update_keys(
    pool: &SqlitePool,
) -> Result<Vec<(String, String)>, AppError> {
    let rows = sqlx::query_as::<_, (String, String)>(
        "SELECT provider, name FROM skill_source WHERE auto_update = 1 ORDER BY provider, name",
    )
    .fetch_all(pool)
    .await?;
    Ok(rows)
}

/// 모든 provenance 행(상태 표시 + check-all 대상). `get_skill_source`의 select 컬럼/매핑을 재사용.
pub(crate) async fn list_all_sources(pool: &SqlitePool) -> Result<Vec<SkillSource>, AppError> {
    let rows = sqlx::query_as::<
        _,
        (
            i32, String, String, String, Option<String>, Option<String>, String, i64,
            Option<String>, Option<String>,
        ),
    >(
        "SELECT id, provider, name, source_url, source_ref, subpath, installed_commit, \
                auto_update, staged_commit, last_checked_at FROM skill_source \
         ORDER BY provider, name",
    )
    .fetch_all(pool)
    .await?;
    Ok(rows
        .into_iter()
        .map(|r| SkillSource {
            id: r.0,
            provider: r.1,
            name: r.2,
            source_url: r.3,
            source_ref: r.4,
            subpath: r.5,
            installed_commit: r.6,
            auto_update: r.7 != 0,
            staged_commit: r.8,
            last_checked_at: r.9,
        })
        .collect())
}
```

#[derive(Debug, Clone, Serialize, Deserialize, Type)]
#[serde(rename_all = "camelCase")]
pub struct UpdateStatus {
    pub provider: String,
    pub name: String,
    pub installed_commit: String,
    pub staged_commit: Option<String>,
    pub auto_update: bool,
    pub last_checked_at: Option<String>,
    /// staging에 installed와 다른 commit가 받아져 있으면 true(적용 가능).
    pub update_available: bool,
}

/// provenance 1행 → UpdateStatus. update_available = staged가 있고 installed와 다름.
pub(crate) fn status_from_source(s: &SkillSource) -> UpdateStatus {
    let update_available = s
        .staged_commit
        .as_deref()
        .is_some_and(|c| c != s.installed_commit);
    UpdateStatus {
        provider: s.provider.clone(),
        name: s.name.clone(),
        installed_commit: s.installed_commit.clone(),
        staged_commit: s.staged_commit.clone(),
        auto_update: s.auto_update,
        last_checked_at: s.last_checked_at.clone(),
        update_available,
    }
}

/// staging 스킬 dir(`<staging_root>/<provider>/<name>`).
pub(crate) fn staging_skill_dir(staging_root: &Path, provider: &str, name: &str) -> PathBuf {
    staging_root.join(provider).join(name)
}

/// content_dir(검증된 SKILL.md 포함)를 staging/<provider>/<name>/로 복사. 재호출 멱등(기존 제거 후 복사).
/// 심링크는 따르지 않는다(central_repo::import_to_central 계약 재사용). 테스트 가능(앱 핸들 비의존).
pub(crate) fn stage_from_dir(
    staging_root: &Path,
    provider: &str,
    name: &str,
    content_dir: &Path,
) -> Result<PathBuf, AppError> {
    // import_to_central은 "src dir → dest dir 복사(기존 제거 후, 심링크 skip)"라 staging에도 그대로 맞다.
    crate::skills::central_repo::import_to_central(staging_root, provider, name, content_dir)
}

/// dest dir의 얕은 파일 수(audit detail용 — 내용 미열람).
fn count_files(dir: &Path) -> usize {
    std::fs::read_dir(dir)
        .map(|rd| rd.flatten().filter(|e| e.file_type().map(|ft| ft.is_file()).unwrap_or(false)).count())
        .unwrap_or(0)
}

/// core: 가역 apply(hermetic). 순서 = ① staged_commit 존재 검증(없으면 NotFound) → ② **사전 전체 백업**
/// (PR2 backup_library_core — 적용을 가역으로) → ③ central<-staging 교체(import_to_central 재사용) →
/// ④ installed_commit 승격 + staged 비움 → ⑤ staging 정리 → ⑥ audit("update_apply"). 잡 spawn 0(#1/#2).
#[allow(clippy::too_many_arguments)]
pub(crate) async fn apply_update_core(
    pool: &SqlitePool,
    central_root: &Path,
    staging_root: &Path,
    backups_root: &Path,
    provider: &str,
    name: &str,
    backup_id: &str,
) -> Result<Skill, AppError> {
    let source = get_skill_source(pool, provider, name)
        .await?
        .ok_or_else(|| AppError::not_found("skills.update.no_source", "업데이트 출처 정보가 없습니다.".to_string()))?;
    let staged = source.staged_commit.clone().ok_or_else(|| {
        AppError::not_found("skills.update.nothing_staged", "적용할 업데이트가 없습니다.".to_string())
    })?;
    let staged_dir = staging_skill_dir(staging_root, provider, name);
    if !staged_dir.join("SKILL.md").is_file() {
        return Err(AppError::not_found(
            "skills.update.staged_missing",
            "staging에 받아둔 업데이트를 찾을 수 없습니다.".to_string(),
        ));
    }

    // ② 사전 전체 백업(적용 직전 상태 보존 → restore UI로 되돌릴 수 있음).
    crate::skills::backup::backup_library_core(pool, central_root, backups_root, backup_id).await?;

    // ③ central 교체(기존 제거 후 staging 내용 복사).
    let dest = import_to_central(central_root, provider, name, &staged_dir)?;

    // ④ commit 승격 + staged 비움.
    promote_staged_commit(pool, provider, name, &staged).await?;

    // ⑤ staging 정리.
    if staged_dir.exists() {
        std::fs::remove_dir_all(&staged_dir)?;
    }

    // ⑥ audit(비밀-free: 파일 수 + commit).
    let detail = format!("files={},commit={}", count_files(&dest), staged);
    audit(pool, "update_apply", "managed_skill", &dest.to_string_lossy(), Some(&source.source_url), Some(&detail)).await?;

    // 반환 Skill = install_from_dir와 동일 형태.
    let md = dest.join("SKILL.md");
    let content = std::fs::read_to_string(&md).unwrap_or_default();
    let (fm_name, fm_desc) = parse_frontmatter(&content);
    let prov = match provider {
        "claude" => SkillProvider::Claude,
        "codex" => SkillProvider::Codex,
        "openclaw" => SkillProvider::Openclaw,
        "hermes" => SkillProvider::Hermes,
        _ => SkillProvider::Other,
    };
    let _ = provider_segment(prov); // provider 문자열 ↔ enum 왕복 일관성(컴파일 가드).
    Ok(Skill {
        id: format!("managed:{}", md.to_string_lossy()),
        name: fm_name.unwrap_or_else(|| name.to_string()),
        kind: "managed".into(),
        prompt: Some(fm_desc.unwrap_or_default()),
        binding: None,
        rail: None,
        enabled: true,
        model: None,
        reasoning_effort: None,
        fast_mode: false,
        source_path: Some(md.to_string_lossy().into_owned()),
        provider: Some(prov),
        tags: Vec::new(),
        fallback_prompt: None,
        created_at: String::new(),
        updated_at: String::new(),
    })
}
```

/// 한 source 업스트림 확인 + (새 commit이면) staging. 네트워크(bounded fetch). 공개 우선 token=None.
async fn check_one(
    pool: &SqlitePool,
    staging_root: &Path,
    source: &SkillSource,
) -> Result<(), AppError> {
    let parsed = parse_source(&source.source_url).ok_or_else(|| {
        AppError::terminal("skills.update.bad_source", format!("출처 URL 파싱 실패: {}", source.source_url))
    })?;
    let gz = fetch_tarball_bytes(&parsed, None).await?;
    let (tmp, top) = extract_tarball(&gz)?;
    let upstream = commit_from_top_level(&top);
    let checked = now_iso();

    if upstream == source.installed_commit {
        // 최신 — staging 비움(이전에 staged였다면 해소) + 확인 시각만.
        record_update_check(pool, &source.provider, &source.name, None, &checked).await?;
        return Ok(());
    }

    // 새 버전 — content dir(subpath) 해석 후 staging.
    let mut content_dir = tmp.path().join(&top);
    if let Some(sub) = &parsed.subpath {
        for seg in sub.split('/').filter(|s| !s.is_empty()) {
            content_dir = content_dir.join(sanitize_segment(seg));
        }
    }
    if !content_dir.join("SKILL.md").is_file() {
        return Err(AppError::not_found("skills.update.subpath_missing", "업데이트 콘텐츠를 찾을 수 없습니다.".to_string()));
    }
    let staged_dest = stage_from_dir(staging_root, &source.provider, &source.name, &content_dir)?;
    record_update_check(pool, &source.provider, &source.name, Some(&upstream), &checked).await?;
    audit(pool, "update_stage", "managed_skill", &staged_dest.to_string_lossy(), Some(&source.source_url),
          Some(&format!("commit={upstream}"))).await?;
    Ok(())
}

pub(crate) async fn check_all_core(pool: &SqlitePool, staging_root: &Path) -> Result<Vec<UpdateStatus>, AppError> {

}
