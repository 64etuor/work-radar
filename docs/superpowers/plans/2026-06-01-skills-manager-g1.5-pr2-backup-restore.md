# G1.5-PR2 — Skill Library Backup / Restore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add versioned, reversible on-disk snapshots of the central skill library (`skills-library`) with a pre-restore safety snapshot, so any install/state change is recoverable — ADR-0006 reversibility rail, fetch/job-free.

**Architecture:** A new pure-fs+DB module `src-tauri/src/skills/backup.rs` copies the whole `skills-library` tree into `app_data_dir/skills-backups/<utc-ts>/` (snapshot id = timestamp dir name). Restore takes a pre-restore safety snapshot first, replaces the central tree from the chosen snapshot, then reconciles `skill_source` provenance rows (prunes orphans). Three `Result<_, AppError>` IPC commands surface it; the SkillsView gets a backup/restore panel with an inline two-step confirm (no nested overlay — avoids the Sheet Esc-contract burden). No network, no token, no codex-job spawn (#1/#2 hold trivially: file copy + DB only).

**Tech Stack:** Rust (sqlx SQLite, `chrono::Utc` for the snapshot id, `tempfile` in tests), tauri-specta typed bindings, React + @tanstack/react-query, shadcn/ui (existing `Sheet`/`Button`/`Input`).

```rust
/// 백업 스냅샷 1건의 메타. specta는 i64(BigInt) export 금지 → 개수는 i32, 바이트는 f64
/// (JS number — 2^53까지 정수 정확, 스킬 텍스트 트리엔 충분). id = 스냅샷 디렉터리명(UTC 타임스탬프).
#[derive(Debug, Clone, Serialize, Deserialize, Type)]
#[serde(rename_all = "camelCase")]
pub struct BackupMeta {
    pub id: String,
    pub created_at: String, // ISO8601 UTC (= id에서 파생, 표시용)
    pub skill_count: i32,
    pub bytes: f64,
}

/// 디렉터리 트리의 총 바이트(파일 크기 합). 부재/읽기불가 엔트리는 0으로 무시(메타용 best-effort).
fn dir_size_bytes(root: &Path) -> u64 {
    let mut total = 0u64;
    let Ok(entries) = std::fs::read_dir(root) else {
        return 0;
    };
    for entry in entries.flatten() {
        let Ok(ft) = entry.file_type() else { continue };
        if ft.is_symlink() {
            continue; // 스냅샷은 심링크를 따르지 않으므로 크기에도 넣지 않는다.
        } else if ft.is_dir() {
            total += dir_size_bytes(&entry.path());
        } else if ft.is_file() {
            total += entry.metadata().map(|m| m.len()).unwrap_or(0);
        }
    }
    total
}

/// `id`에서 ISO8601 표시 문자열 파생(폴백: id 그대로). `20260601T123045Z` → `2026-06-01T12:30:45Z`.
fn created_at_from_id(id: &str) -> String {
    let b = id.as_bytes();
    if id.len() == 16 && id.ends_with('Z') && b[8] == b'T' {
        format!(
            "{}-{}-{}T{}:{}:{}Z",
            &id[0..4],
            &id[4..6],
            &id[6..8],
            &id[9..11],
            &id[11..13],
            &id[13..15],
        )
    } else {
        id.to_string()
    }
}

/// 한 스냅샷 dir → 메타(개수 = SKILL.md 가진 dir 수, 바이트 = 트리 합).
fn meta_for_snapshot(snapshot_root: &Path, id: &str) -> BackupMeta {
    let skill_count = list_managed_dirs(snapshot_root).len() as i32;
    BackupMeta {
        id: id.to_string(),
        created_at: created_at_from_id(id),
        skill_count,
        bytes: dir_size_bytes(snapshot_root) as f64,
    }
}

/// 중앙 라이브러리 트리를 `<backups_root>/<id>/`로 복사한다. central 부재면 빈 스냅샷 dir만 만든다.
/// 심링크는 따르지 않는다(central_repo::copy_dir_shallow 계약 — 스냅샷이 트리 밖으로 새지 않음).
fn snapshot_into(central_root: &Path, backups_root: &Path, id: &str) -> Result<PathBuf, AppError> {
    let seg = sanitize_segment(id); // id는 코드 생성이지만 경로 세그먼트 안전 보장(방어적).
    let dest = backups_root.join(&seg);
    if dest.exists() {
        std::fs::remove_dir_all(&dest)?; // 같은 초에 두 번 호출돼도 멱등.
    }
    std::fs::create_dir_all(&dest)?;
    if central_root.is_dir() {
        copy_dir_shallow(central_root, &dest)?;
    }
    Ok(dest)
}

/// core: 스냅샷 + audit. 테스트 가능(앱 핸들 비의존). `id`는 호출자(커맨드)가 UTC로 생성해 주입한다
/// (installer가 installed_commit을 주입하는 것과 동일 — 결정성/hermetic 테스트).
pub(crate) async fn backup_library_core(
    pool: &SqlitePool,
    central_root: &Path,
    backups_root: &Path,
    id: &str,
) -> Result<BackupMeta, AppError> {
    let dest = snapshot_into(central_root, backups_root, id)?;
    let meta = meta_for_snapshot(&dest, id);
    let detail = format!("skills={}", meta.skill_count); // 비밀-free: 개수만.
    audit(
        pool,
        "backup",
        "skill_library",
        &dest.to_string_lossy(),
        None,
        Some(&detail),
    )
    .await?;
    Ok(meta)
}

/// `<backups_root>` 하위 스냅샷들의 메타(최신 먼저 — id가 정렬 가능한 타임스탬프). 부재 root = 빈 vec.
pub(crate) fn list_backups_core(backups_root: &Path) -> Result<Vec<BackupMeta>, AppError> {
    let mut out = Vec::new();
    let Ok(entries) = std::fs::read_dir(backups_root) else {
        return Ok(out); // 백업 디렉터리 부재 → 0건(no-op).
    };
    for entry in entries.flatten() {
        if entry.file_type().map(|ft| ft.is_dir()).unwrap_or(false) {
            let id = entry.file_name().to_string_lossy().into_owned();
            out.push(meta_for_snapshot(&entry.path(), &id));
        }
    }
    out.sort_by(|a, b| b.id.cmp(&a.id)); // 최신(큰 타임스탬프) 먼저.
    Ok(out)
}
```

```rust
/// core: 가역 복원. 순서가 가역성의 핵심이다 —
/// 1) 요청 스냅샷 존재 검증(없으면 central 무변경으로 NotFound),
/// 2) **사전 안전 스냅샷**(복원 직전 central 상태)을 떠서 복원 자체를 undo 가능하게,
/// 3) central 트리를 스냅샷 내용으로 교체,
/// 4) provenance 행 화해(복원으로 사라진 managed 스킬의 고아 행 prune — 콘텐츠-without-row는 그대로),
/// 5) audit(레일 ①, 경로/개수만).
pub(crate) async fn restore_library_core(
    pool: &SqlitePool,
    central_root: &Path,
    backups_root: &Path,
    snapshot_id: &str,
    safety_id: &str,
) -> Result<(), AppError> {
    let snap_seg = sanitize_segment(snapshot_id);
    let snapshot = backups_root.join(&snap_seg);
    if !snapshot.is_dir() {
        return Err(AppError::not_found(
            "skills.restore.snapshot_missing",
            "요청한 백업 스냅샷을 찾을 수 없습니다.".to_string(),
        ));
    }

    // 2) 사전 안전 스냅샷(복원 직전 상태). 이게 있어야 복원이 그 자체로 가역.
    snapshot_into(central_root, backups_root, safety_id)?;

    // 3) central 교체: 기존 트리 제거 후 스냅샷 내용 복사.
    if central_root.exists() {
        std::fs::remove_dir_all(central_root)?;
    }
    std::fs::create_dir_all(central_root)?;
    copy_dir_shallow(&snapshot, central_root)?;

    // 4) provenance 화해: SKILL.md가 사라진 (provider,name) 행은 고아 → 삭제.
    let mut pruned = 0usize;
    for (provider, name) in all_skill_source_keys(pool).await? {
        let dir = central_skill_dir(central_root, &provider, &name);
        if !dir.join("SKILL.md").is_file() {
            delete_skill_source(pool, &provider, &name).await?;
            pruned += 1;
        }
    }

    // 5) audit. detail은 비밀-free: 스냅샷 id + 안전 스냅샷 id + prune 수.
    let detail = format!("from={snapshot_id},safety={safety_id},pruned={pruned}");
    audit(
        pool,
        "restore",
        "skill_library",
        &central_root.to_string_lossy(),
```

```ts
export function useRestoreSkillLibrary() {
```

- [ ] **Step 4: Implement `BackupPanel` with inline two-step restore confirm**

Add this component next to `InstallPanel` (~line 1261) in `src/components/SkillsView.tsx`. The restore confirm is an inline two-step toggle (no nested Dialog → no overlay-stack / Esc-contract burden inside the Sheet):

```tsx
function BackupPanel({ onDone }: { onDone: () => void }) {
  const backups = useSkillBackups();
  const backup = useBackupSkillLibrary();
  const restore = useRestoreSkillLibrary();
  const [confirmId, setConfirmId] = useState<string | null>(null);
  const [note, setNote] = useState<string | null>(null);

  const doBackup = () => {
    if (backup.isPending) return;
    setNote(null);
    backup.mutate(undefined, {
      onSuccess: (m) => setNote(`백업 완료: ${m.skillCount}개 스킬 (${m.id})`),
      onError: (e) => setNote(`백업 실패: ${(e as Error).message}`),
    });
  };

  const doRestore = (id: string) => {
    if (restore.isPending) return;
    setNote(null);
    restore.mutate(id, {
      onSuccess: () => {
        setConfirmId(null);
        onDone();
      },
      onError: (e) => setNote(`복원 실패: ${(e as Error).message}`),
    });
  };

  return (
    <div className="skl-edit">
      <p className="skl-desc">
        중앙 라이브러리 전체를 타임스탬프 스냅샷으로 백업합니다. 복원은 직전 상태를 안전 스냅샷으로
        보존한 뒤 교체하므로 되돌릴 수 있습니다. 모든 작업은 로컬 파일 복사이며 감사됩니다.
      </p>
      <div className="skl-actions">
        <Button className="gap-1.5 rounded-full" onClick={doBackup} disabled={backup.isPending}>
          <Archive className="size-4" />
          {backup.isPending ? "백업 중…" : "지금 백업"}
        </Button>
        <Button variant="outline" className="rounded-full" onClick={onDone}>
          닫기
        </Button>
      </div>
      {note && <span className="skl-note">{note}</span>}

      <ul className="skl-backup-list">
        {(backups.data ?? []).map((b) => (
          <li key={b.id} className="skl-backup-row">
            <span className="font-mono">{b.createdAt}</span>
            <span className="skl-desc">{b.skillCount}개 스킬</span>
            {confirmId === b.id ? (
              <span className="skl-actions">
                <Button
                  size="sm"
                  className="rounded-full"
                  onClick={() => doRestore(b.id)}
                  disabled={restore.isPending}
                >
                  {restore.isPending ? "복원 중…" : "정말 복원"}
                </Button>
                <Button
                  size="sm"
                  variant="outline"
                  className="rounded-full"
                  onClick={() => setConfirmId(null)}
                >
                  취소
                </Button>
              </span>
            ) : (
              <Button
                size="sm"
                variant="outline"
                className="rounded-full"
                onClick={() => setConfirmId(b.id)}
              >
                복원…
              </Button>
            )}
          </li>
        ))}
        {backups.data?.length === 0 && <li className="skl-desc">아직 백업이 없습니다.</li>}
      </ul>
    </div>
  );
}
```
