# Boule v3 Phase H — Control Room UI (Slice 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only in-app **Control Room** view to work-radar that renders the Boule governance harness's derived `state/*.json` projections (tasks/plans/specs/sessions/handoffs/orchestrator-view) through one thin specta-typed Tauri command, across four status panels.

**Architecture:** A new Rust module (`src-tauri/src/governance/snapshot.rs`) resolves the governance `workspace/state` dir (compile-time default + `WORK_RADAR_GOVERNANCE_WORKSPACE` env override), reads each `state/*.json` (absent ⇒ empty, corrupt ⇒ `AppError`, newest mtime ⇒ `generatedAt`), and returns a `ControlRoomSnapshot`. One `#[tauri::command] #[specta::specta] get_control_room_snapshot` exposes it; `cargo test` regenerates `src/bindings.ts`. A new shadcn React view (`ControlRoomView.tsx`) reads it via a react-query hook and renders System Overview · Agent Session Board · Handoff Queue · Work Lists. **No write path to the governance event log, no approval surface, no rebuild trigger.**

**Tech Stack:** Rust (Tauri 2, specta/tauri-specta rc.25, serde, serde_json, chrono) · TypeScript/React (shadcn/ui, lucide, @tanstack/react-query, Tailwind v4 `@theme` tokens) · governance derived JSON (read-only).

**Spec:** `governance/docs/design/2026-06-03-boule-v3-phase-h-control-room-ui-design.md`

**Invariants in scope (first app-touching phase):** #4 specta drift gate (regenerate + commit `bindings.ts`, CI `git diff` must pass) · #6 no app SQLite/migration change · #7 shadcn/lucide/Tailwind-v4 tokens · #1 structural (no event write path) · #2/#3/#5 trivially held (no tokens/network/loops).

```rust
/// Read one axis file. Absent ⇒ `T::default()` (axis not yet projected). Corrupt ⇒ terminal error.
/// Records the file's mtime into `newest` when present.
fn read_axis<T>(
    state_dir: &Path,
    file: &str,
    newest: &mut Option<std::time::SystemTime>,
) -> Result<T, AppError>
where
    T: serde::de::DeserializeOwned + Default,
{
    let path = state_dir.join(file);
    let meta = match std::fs::metadata(&path) {
        Ok(m) => m,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(T::default()),
        Err(e) => return Err(AppError::terminal("governance.stat_failed", format!("{file}: {e}"))),
    };
    if let Ok(modified) = meta.modified() {
        if newest.map_or(true, |n| modified > n) {
            *newest = Some(modified);
        }
    }
    let raw = std::fs::read_to_string(&path)
        .map_err(|e| AppError::terminal("governance.read_failed", format!("{file}: {e}")))?;
    serde_json::from_str::<T>(&raw)
        .map_err(|e| AppError::terminal("governance.parse_failed", format!("{file}: {e}")))
}

/// Read all six derived projection files into a single read-only snapshot.
pub fn read_snapshot(state_dir: &Path) -> Result<ControlRoomSnapshot, AppError> {
    let mut newest: Option<std::time::SystemTime> = None;
    let tasks = read_axis::<Vec<TaskRow>>(state_dir, "tasks.json", &mut newest)?;
    let plans = read_axis::<Vec<PlanRow>>(state_dir, "plans.json", &mut newest)?;
    let specs = read_axis::<Vec<SpecRow>>(state_dir, "specs.json", &mut newest)?;
    let sessions = read_axis::<Vec<SessionRow>>(state_dir, "sessions.json", &mut newest)?;
    let handoffs = read_axis::<Vec<HandoffRow>>(state_dir, "handoffs.json", &mut newest)?;
    let orchestrator = read_axis::<OrchestratorView>(state_dir, "orchestrator-view.json", &mut newest)?;
    let generated_at = newest.map(|t| chrono::DateTime::<chrono::Utc>::from(t).to_rfc3339());
    Ok(ControlRoomSnapshot { generated_at, tasks, plans, specs, sessions, handoffs, orchestrator })
}

import type {
  SessionRow,
  SessionPhase,
  TaskPhase,
  PlanPhase,
  SpecPhase,

/** Master §12 node-status buckets, collapsed to the tones the UI renders. */
export type StatusTone = "done" | "active" | "waiting" | "pressure" | "blocked" | "muted";

type AnyPhase = SessionPhase | TaskPhase | PlanPhase | SpecPhase | HandoffPhase;

export function statusTone(phase: AnyPhase): StatusTone {
  switch (phase) {
    case "done":
    case "completed":
    case "consumed":
    case "accepted":
      return "done";
    case "active":
    case "opening":
      return "active";
    case "waiting":
    case "needs_revision":
    case "validating":
    case "ready":
    case "requested":
    case "planned":
    case "draft":
      return "waiting";
    case "context_pressure_high":
    case "checkpoint_requested":
    case "handoff_ready":
    case "pending":
    case "recovering":
      return "pressure";
    case "blocked":
    case "crashed":
    case "invalid":
      return "blocked";
    case "closed":
    case "closing":
    case "cancelled":
    case "archived":
    case "superseded":
    case "unknown":
      return "muted";
    default:
      return "muted";
  }
}

export interface SessionBuckets {
  active: SessionRow[];
  waiting: SessionRow[];
  pressure: SessionRow[];
  terminal: SessionRow[];
}

export function bucketSessions(sessions: SessionRow[]): SessionBuckets {
  const out: SessionBuckets = { active: [], waiting: [], pressure: [], terminal: [] };
  for (const s of sessions) {
    const tone = statusTone(s.phase);
    if (tone === "active") out.active.push(s);
    else if (tone === "pressure") out.pressure.push(s);
    else if (tone === "muted") out.terminal.push(s);
    else out.waiting.push(s); // waiting + blocked share the "needs attention" column
  }
  return out;
}

/** Humanize the snapshot mtime. `nowMs` is injected so the function is pure/testable. */
export function relativeAgo(generatedAt: string | null, nowMs: number): string {
  if (!generatedAt) return "아직 프로젝션 없음";
  const then = Date.parse(generatedAt);
  if (Number.isNaN(then)) return "프로젝션 시각 불명";
  const mins = Math.max(0, Math.round((nowMs - then) / 60_000));
  if (mins === 0) return "방금 프로젝션";
  if (mins < 60) return `${mins}분 전 프로젝션`;
  const hrs = Math.round(mins / 60);
  return `${hrs}시간 전 프로젝션`;
}
```
