# Boule P2b — Ask-User Card (work-radar slice) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render an agent-initiated "ask the user" prompt as a tappable shadcn card in the work-radar Hermes panel, and route the user's choice back to the agent over ACP — a bespoke `hermes-agent:ask-user` event + `hermes_ask_user_respond` specta command, fully headless-verified.

**Architecture:** The only new wire behavior is handling an inbound ACP agent **request** (`session/request_permission`, today silently dropped at `acp_client.rs:390`). A pure helper normalizes it into a generic shape, `dispatch_incoming` emits `hermes-agent:ask-user`, the frontend reducer appends a `role:"ask"` message, `HermesChatLog` renders a card, and a tap calls `hermes_ask_user_respond` which writes the JSON-RPC response (echoing the agent's request id) to the session's stdin. The request id is the correlation token, so no server-side pending map is needed. Dismiss → `cancelled` outcome so the agent never hangs.

**Tech Stack:** Rust (tauri 2, tauri-specta, serde_json, tokio mpsc), TypeScript/React (zustand reducer, shadcn/ui Button, Tailwind v4), vitest (node env — `renderToStaticMarkup`, no jsdom/RTL).

명령 정본: `docs/reference/commands.md`. IPC 규율: `docs/areas/ipc-conventions.md`. 카드=shadcn: `docs/areas/shadcn-migration.md` + `DESIGN.md`.

/// Normalized "ask the user" payload emitted to the frontend (bespoke generic shape;
/// ACP semantics never cross the IPC boundary).
#[derive(Debug, Clone, PartialEq)]
pub(crate) struct AskUserOption {
    pub id: String,
    pub label: String,
}

#[derive(Debug, Clone, PartialEq)]
pub(crate) struct AskUser {
    /// Original JSON-RPC request id, stringified (specta forbids i64/u64; echoed back
    /// with its original JSON type by `build_ask_user_response`).
    pub request_id: String,
    pub tool_name: Option<String>,
    pub options: Vec<AskUserOption>,
}

/// Translate an inbound ACP `session/request_permission` request frame into an `AskUser`.
/// Returns `None` for any other method, a frame without an id (a notification), or one
/// with no usable options. Tolerant: options missing `optionId` are skipped; a missing
/// `name` falls back to the `optionId` as the label (graceful degrade — the exact ACP
/// option schema is unverified pending the deferred live smoke).
pub(crate) fn parse_permission_request(val: &Json) -> Option<AskUser> {
    if val.get("method").and_then(|v| v.as_str()) != Some("session/request_permission") {
        return None;
    }
    let request_id = match val.get("id")? {
        Json::Number(n) => n.to_string(),
        Json::String(s) => s.clone(),
        _ => return None,
    };
    let params = val.get("params")?;
    let raw_options = params.get("options")?.as_array()?;
    let mut options = Vec::new();
    for opt in raw_options {
        let Some(option_id) = opt.get("optionId").and_then(|v| v.as_str()) else {
            continue;
        };
        let label = opt
            .get("name")
            .and_then(|v| v.as_str())
            .unwrap_or(option_id)
            .to_string();
        options.push(AskUserOption {
            id: option_id.to_string(),
            label,
        });
    }
    if options.is_empty() {
        return None;
    }
    let tool_name = params
        .get("toolCall")
        .and_then(|tc| tc.get("title"))
        .and_then(|v| v.as_str())
        .map(|s| s.to_string());
    Some(AskUser {
        request_id,
        tool_name,
        options,
    })
}

/// Build the JSON-RPC **response** body for an ask-user request. Echoes `request_id`
/// preserving its original JSON type (numeric string → number). `cancelled` sends the
/// ACP `cancelled` outcome (so a dismissed card never hangs the agent).
pub(crate) fn build_ask_user_response(request_id: &str, option_id: &str, cancelled: bool) -> Vec<u8> {
    let id = match request_id.parse::<i64>() {
        Ok(n) => json!(n),
        Err(_) => json!(request_id),
    };
    let outcome = if cancelled {
        json!({ "outcome": "cancelled" })
    } else {
        json!({ "outcome": "selected", "optionId": option_id })
    };
    let resp = json!({ "jsonrpc": "2.0", "id": id, "result": { "outcome": outcome } });
    serde_json::to_vec(&resp).unwrap_or_default()
}
```

/// Route the user's ask-user card choice back to the agent as a JSON-RPC response,
/// echoing the original request id. `cancelled=true` sends the ACP `cancelled` outcome
/// (dismissed card → agent unblocks rather than hangs). Missing session = graceful no-op.
#[tauri::command]
#[specta::specta]
pub async fn hermes_ask_user_respond(
    holder: State<'_, HermesAgentHolder>,
    tab_id: String,
    request_id: String,
    option_id: String,
    cancelled: bool,
) -> Result<(), AppError> {
    let stdin_tx = {
        let map = holder.read().await;
        map.get(&tab_id).map(|s| s.stdin_tx.clone())
    };
    if let Some(stdin_tx) = stdin_tx {
        let body = crate::hermes_agent::acp_client::build_ask_user_response(
            &request_id,
            &option_id,
            cancelled,
        );
        let frame = crate::hermes_agent::frame::encode_frame(&body);
        stdin_tx
            .send(frame)
            .await
            .map_err(|_| AppError::unexpected("hermes.acp.protocol", "stdin closed"))?;
    }
    Ok(())
}
```

```tsx
import { Button } from "@/components/ui/button";
import { cn } from "@/lib/utils";

import type { HermesMessage } from "./types";

type AskMessage = Extract<HermesMessage, { role: "ask" }>;

interface Props {
  message: AskMessage;
  /** (optionId, cancelled) — optionId is "" when cancelled. */
  onRespond: (optionId: string, cancelled: boolean) => void;
}

/** Agent-initiated "ask the user" prompt rendered as a tappable shadcn card.
 *  Pure presentational — all routing is delegated to `onRespond`. */
export function AskUserCard({ message, onRespond }: Props) {
  const resolved = message.resolved;
  const isResolved = resolved !== undefined;
  const cancelled = resolved === "cancelled";

  return (
    <div className="border-border bg-muted/30 my-1 rounded-lg border p-3 text-left">
      {message.toolName && (
        <p className="text-muted-foreground mb-2 font-mono text-xs">{message.toolName}</p>
      )}
      <div className="flex flex-col gap-1.5">
        {message.options.map((o) => {
          const chosen = resolved === o.id;
          return (
            <Button
              key={o.id}
              type="button"
              variant={chosen ? "default" : "outline"}
              aria-pressed={chosen}
              disabled={isResolved}
              className={cn("justify-start", chosen && "font-medium")}
              onClick={() => onRespond(o.id, false)}
            >
              {o.label}
            </Button>
          );
        })}
      </div>
      {!isResolved ? (
        <button
          type="button"
          className="text-muted-foreground hover:text-foreground mt-2 text-xs underline"
          onClick={() => onRespond("", true)}
        >
          취소
        </button>
      ) : (
        <p className="text-muted-foreground mt-2 text-xs">{cancelled ? "취소됨" : "응답함"}</p>
      )}
    </div>
  );
}
```
